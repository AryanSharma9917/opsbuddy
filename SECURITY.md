# Security Policy

## Supported versions

The project is currently supported on the latest main branch. Security fixes are
reviewed and merged there first.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Reach out privately to
The maintainer through the repository owner, or by using the project’s private
contact path.

Include:

- a clear description of the issue
- reproduction steps or a proof of concept when possible
- the impact and any affected environment details

## Responsible disclosure

We appreciate responsible disclosure. Please avoid sharing details publicly until
an issue has been reviewed and remediated.

## Safe use guidance

OpsBuddy is a local troubleshooting assistant for learning and investigation. It
should be used with caution in production environments and should never be given
credentials, secrets, or sensitive environment details that are not explicitly
needed for a local diagnostic workflow.
